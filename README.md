# ClusterTwo releases

Signed Android APKs for ClusterTwo, a second instrument cluster for the car on
an Android tablet. Source is kept in a separate repository.

**Install:** open the [latest release](https://github.com/briansl/Releases/releases/latest)
on the tablet's browser, download the `.apk`, and allow the install when
Android asks. Each release's notes include the file's SHA-256. New versions
install over the old one and keep settings.
